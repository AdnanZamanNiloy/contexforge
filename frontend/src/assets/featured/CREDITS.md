# Featured notebook cover images

Photographs used as the cover art for the featured project templates in
`frontend/src/assets/featured/`. Each image was chosen to match its notebook's
topic, and the files are served unmodified — CSS crops them to the cover frame,
so no derivative is produced.

Attribution is recorded here as the CC BY / CC BY-SA licences require. The
abstract cover artwork in `ProjectsPage.jsx` is still used for a user's own
projects, which have no photograph associated with them.
